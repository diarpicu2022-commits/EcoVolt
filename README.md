# EcoVolt - Sistema Inteligente de Energía Solar

EcoVolt es un sistema inteligente de monitoreo y gestión de energía solar. Permite recolectar, analizar y visualizar datos de paneles solares en tiempo real, con el objetivo de optimizar el rendimiento energético y facilitar la toma de decisiones.

## Descripción

El sistema integra un backend para el procesamiento y almacenamiento de datos, y un frontend para la visualización interactiva del estado y la producción energética del sistema solar.

## Estructura del proyecto

```
EcoVolt/
├── backend/    # Lógica del servidor, APIs y procesamiento de datos
├── frontend/   # Interfaz de usuario y visualización
├── requirements.txt
└── README.md
```
