🎨 Patrones → Uso Real

Singleton → SystemLogger, DatabaseConnection, SolarSystemConfig
Abstract Factory → SolarPanelFactory (Mono/Poly/ThinFilm)
Builder → EnergyReportBuilder
Prototype → PanelConfigPrototype.clone()
Adapter → SimulatorSensorAdapter / SerialSensorAdapter
Facade → EnergyManagementFacade
Proxy → SensorDataProxy (rate limiting + logging)
Decorator → CalibrationDecorator, ValidationDecorator
State → BatteryState: Charging/Discharging/Full/Low
